# 반려동반 캠핑장 데이터셋 구축

유튜브와 인스타그램의 인기 반려동반 캠핑 콘텐츠를 조사하여, 실제 캠핑장 정보를 Supabase 데이터베이스에 구축합니다. 이후 진행될 검색·비교·저장 화면 work unit이 이 데이터를 기반으로 동작합니다.

## 사용자에게 보이는 결과

- Supabase에 실제로 존재하는 반려동반 가능 캠핑장 데이터가 여러 건 저장되어, 이후 화면 work unit이 진짜 데이터로 검색·비교 기능을 시연할 수 있습니다.
- 이번 work unit 자체는 화면을 만들지 않으므로, 최종 사용자가 직접 눈으로 확인할 결과물은 없습니다.

## 승인된 범위

- 인기 있고 유튜버나 인스타그램 게시자가 좋게 평가한 반려동반 캠핑장을 다루는 유튜브·인스타그램 콘텐츠를 조사합니다.
- 조사한 내용에서 캠핑장명, 지역, 반려견 크기 허용 범위, 편의시설, 장단점 요약, 참고 영상·게시물 정보를 추출합니다.
- 필요한 경우 네이버 지도, 캠핑장 공식 홈페이지, 예약 플랫폼으로 캠핑장의 실제 위치나 운영 여부 같은 기본 사실을 보조로 확인합니다.
- Supabase 프로젝트를 새로 생성하고, 위 정보를 저장할 테이블을 만들어 데이터를 채워넣습니다.

## 수용 기준

- Supabase 프로젝트와 테이블이 생성되어 있고, 앱에서 조회 가능한 상태입니다.
- 경기·강원 지역을 중심으로, 실제로 존재하는 반려동반 가능 캠핑장 데이터가 10곳 이상 저장되어 있습니다.
- 각 캠핑장 데이터는 캠핑장명, 지역, 반려견 크기 허용 범위, 편의시설 태그, 장단점 요약, 참고 영상·게시물 정보(제목 또는 캡션·링크·채널명 또는 계정명)를 모두 포함합니다.
- 데이터는 경기와 강원 두 지역에 걸쳐 분포합니다.
- 참고한 영상이나 게시물은 실제로 존재하며, 2025년 이후 게시된 것이어야 합니다. 원본 게시물의 정확한 링크를 검색으로 특정하지 못한 경우에 한해, 공식 홈페이지나 예약 플랫폼의 신뢰할 수 있는 링크로 대체할 수 있습니다. 이 경우 게시 시기 조건은 적용하지 않습니다.

## 확정된 제약과 근거

- 데이터베이스는 Supabase를 사용합니다. `PRODUCT.md` 정의 단계에서 사용자가 확정한 선택입니다.
- 지역은 경기·강원을 중심으로 조사합니다. 전국을 대상으로 열어두면 조사 범위가 지나치게 넓어지므로, 우선순위를 좁혀 확정했습니다.
- 참고하는 콘텐츠는 2025년 이후 게시분을 기준으로 합니다. 처음에는 캠핑장 자체의 개장 시기(2025년 이후)로 좁히려 했으나, 개장 시기를 확인할 수 있는 소스가 거의 없고 신생 캠핑장은 콘텐츠도 부족해 실현이 어려웠습니다. 최신 정보를 우선한다는 취지는 살리면서 검증 가능한 조건으로 콘텐츠 게시 시기를 대신 채택했습니다.
- 핵심 필터는 반려견 크기 허용 범위, 애견운동장, 개별울타리 세 가지로 유지합니다. 차박 가능 여부는 이번 범위에 포함하지 않습니다.
- 데이터는 자동 수집 파이프라인이 아니라, 이번 work unit에서 직접 조사해 채워넣는 일회성 구축입니다. 자동 수집은 학습 템플릿 규모를 넘어서는 별도 작업이라 이번 범위에서 제외했습니다.
- 캠핑장 정보와 평가는 유튜브와 인스타그램 콘텐츠에서 가져옵니다. 사이트 자체의 사용자 리뷰나 평점 기능은 두지 않는다는 `PRODUCT.md`의 경계를 그대로 따릅니다.
- 캠핑장 발굴(후보 찾기)은 유튜브와 인스타그램 해시태그 검색으로 진행합니다. `PRODUCT.md`가 두 채널을 정보 원천으로 인정하도록 개정되었습니다. 반려견 커뮤니티 제보처럼 이 두 채널 밖의 원천을 추가하는 것은 여전히 `PRODUCT.md`의 경계를 다시 바꾸는 결정이라 이번 범위에서 제외합니다. 네이버 지도·공식 홈페이지·예약 플랫폼·반려견 캠핑 커뮤니티는 발굴이 아니라, 유튜브·인스타그램으로 이미 찾은 캠핑장의 위치, 운영 여부, 반려견 크기·편의시설 같은 기본 정보를 검증하는 보조 수단으로만 사용합니다.
- 유튜브 Shorts와 인스타그램 게시물은 검색엔진에 잘 인덱싱되지 않아, 발굴 단계에서 존재를 확인한 콘텐츠라도 원본 게시물의 정확한 링크를 다시 찾지 못하는 경우가 있었습니다. 이 경우 참고 링크를 camfit·고캠핑·운영 기관 공식 페이지 같은 신뢰할 수 있는 제3자 정보로 대체하기로 했습니다. 데이터 필드상 `source_platform`에 `web` 값을 추가해 이 경우를 구분합니다.

## 가정

- 가정: 반려동반 가능한 인기 캠핑장을 소개하는, 2025년 이후 게시된 유튜브·인스타그램 콘텐츠가 경기·강원 지역에서 최소 10곳 이상 조사 가능할 만큼 존재합니다.

## 범위 밖

- 캠핑장을 검색·비교·저장하는 화면(프론트엔드 UI)은 포함하지 않습니다. 데이터 구축과 화면 구현을 분리해서 각각 독립적인 work unit으로 다루기로 결정했습니다.
- 유튜브·인스타그램에서 새 콘텐츠를 지속적으로 찾아 자동으로 반영하는 수집 파이프라인은 포함하지 않습니다. `PRODUCT.md`에서 구현 단계로 유보한 사항이며, 이번엔 일회성 데이터 구축까지만 다룹니다.

## 유보된 사항

- 데이터를 이후에 어떻게 갱신하거나 추가할지는 정하지 않았습니다.
- Supabase 프로젝트의 리전, 요금제 등 세부 설정은 구현 시점에 정합니다.

## 남은 위험

- 유튜브·인스타그램 콘텐츠 기반 정보이므로, 캠핑장의 실제 운영 상태(폐업, 정책 변경 등)와 시간이 지나며 어긋날 수 있습니다.
- 조사 가능한 실제 데이터가 목표한 10곳에 못 미칠 수 있습니다. 2025년 이후 게시분으로 좁히면서 후보가 더 줄어들 위험이 있습니다.
