# 반려동반 캠핑장 조회·추천 화면

`pet-camping-dataset` work unit이 Supabase에 채워넣은 반려동반 캠핑장 데이터를,
사용자가 조건으로 좁히고 비교하고 자세히 확인할 수 있는 화면으로 보여줍니다.

## 사용자에게 보이는 결과

- 사이트에 처음 들어오면, 유튜브·인스타그램 원본 콘텐츠로 실제 확인된 캠핑장이 먼저 추천되어 보입니다.
- 지역, 반려견 크기, 시설 조건을 고르면 같은 화면에서 바로 조건에 맞는 캠핑장 목록으로 바뀝니다. 별도 페이지로 이동하지 않습니다.
- 목록 카드만 보고도 캠핑장명, 지역, 반려견 크기 허용 범위, 주요 시설, 한 줄 요약, 정보 출처(유튜브·인스타그램·공식 정보 중 어디서 왔는지)를 파악할 수 있어, 여러 곳을 카드만 훑으며 비교할 수 있습니다.
- 캠핑장을 선택하면 상세 화면에서 실제로 다녀온 사람이 좋았다고 한 점과 아쉽다고 한 점을 나눠서 볼 수 있고, 근거가 된 원본 영상·게시물로 바로 이동할 수 있습니다.
- 원본 게시물 링크를 특정하지 못해 공식 정보(홈페이지·예약 플랫폼)로 대체된 캠핑장은 상세 화면에서 그 사실이 안내됩니다.
- 조건에 맞는 캠핑장이 없으면, 그 사실과 함께 조건을 다시 넓힐 수 있는 방법이 안내됩니다.

## 승인된 범위

- 첫 화면 추천, 조건 검색 결과, 캠핑장 상세 세 화면을 다룹니다.
- 필터는 지역, 반려견 크기 허용 범위, 애견운동장, 개별울타리 네 가지이며, 서로 동시에 적용됩니다(모두 만족하는 캠핑장만 남습니다).
- 조건을 아무것도 고르지 않은 첫 화면 상태에서만 추천 영역이 보입니다. 조건을 하나라도 고르면 추천 영역은 사라지고 조건에 맞는 결과만 보입니다.
- 캠핑장을 저장하거나 찜하는 기능, 사이트 자체의 리뷰·평점 기능은 이번 범위에 포함하지 않습니다. `PRODUCT.md`가 정한 경계이자, 저장은 별도 work unit으로 다루기로 한 결정입니다.
- 로그인 없이 모든 화면을 이용할 수 있습니다. `PRODUCT.md`의 확정 사항입니다.

## 수용 기준

- 조건을 아무것도 고르지 않은 첫 화면에는 "영상으로 확인된 곳" 추천 영역과, 그 아래 나머지 캠핑장을 보여주는 전체 목록이 함께 있습니다.
- 추천 영역에는 `source_platform`이 `youtube` 또는 `instagram`인, 즉 원본 콘텐츠가 실제로 확인된 캠핑장만 노출됩니다. `source_platform`이 `web`인(원본 링크를 특정하지 못해 공식 정보로 대체한) 캠핑장은 추천 영역에 노출되지 않습니다.
- 추천 영역에 노출된 캠핑장은 그 아래 전체 목록에서는 중복으로 나오지 않습니다.
- 지역·반려견 크기·시설 조건을 하나 이상 고르면, 추천 영역이 사라지고 조건에 맞는 캠핑장만 한 목록으로 보입니다. 이때는 방금 전 추천 영역에 있던 캠핑장이라도 조건에 맞으면 다시 포함됩니다.
- 반려견 크기 조건은 "이 크기까지 허용"이라는 포함 관계로 동작합니다. 예를 들어 대형견을 고르면 대형견까지 받는 캠핑장만 남고, 소형견을 고르면 소형견만 받는 곳뿐 아니라 중형견·대형견까지 받는 곳도 모두 남습니다.
- 조건에 맞는 캠핑장이 하나도 없으면, 그 사실을 알리고 조건을 초기화할 수 있는 방법을 제공합니다.
- 목록의 각 카드에는 캠핑장명, 지역, 반려견 크기 허용 범위, 시설 태그, 한 줄 요약, 정보 출처(플랫폼과 채널명·계정명)가 표시됩니다.
- 캠핑장 카드를 선택하면 상세 화면으로 이동하고, 상세 화면에는 좋았던 점과 아쉬운 점이 구분되어 보이며, 지역·반려견 크기·시설을 포함한 기본 정보와, 참고한 콘텐츠의 캡션(또는 제목)·채널명(또는 계정명)·원본 링크가 보입니다.
- `source_platform`이 `web`인 캠핑장의 상세 화면에는, 원본 게시물 링크를 특정하지 못해 공식 정보로 대체했다는 안내 문구가 추가로 보입니다.
- 상세 화면에서 목록으로 돌아오면, 직전에 고른 조건과 목록 상태가 그대로 유지됩니다.

## 확정된 제약과 근거

- 추천 기준은 원본 콘텐츠(유튜브·인스타그램) 확인 여부입니다. 조회수나 평점처럼 인기를 나타내는 필드가 데이터에 없어서, "실제로 다녀온 사람의 평가에 기반한 믿을 수 있는 정보"라는 `PRODUCT.md`의 경험 원칙과 가장 직접적으로 연결되는 기준을 채택했습니다.
- 조건 검색은 같은 화면 안에서 상태만 바뀌고, 별도 결과 페이지로 이동하지 않습니다. 데이터가 10~20곳 규모라 페이지 전환 없이도 한 화면에서 다룰 수 있고, 여러 조건을 빠르게 바꿔가며 비교하는 데 유리하다고 판단했습니다.
- 목록 카드에는 사진을 넣지 않습니다. 데이터셋에 이미지 필드가 없기 때문입니다. 이미지를 다룰지는 이번 범위 밖입니다.
- 핵심 필터 네 가지(지역, 반려견 크기, 애견운동장, 개별울타리)는 `pet-camping-dataset` work unit에서 이미 확정된 데이터 필드를 그대로 따릅니다. 차박 가능 여부는 그 work unit에서부터 범위 밖이라 이번 필터에도 없습니다.

## 가정

- 가정: 캠핑장 데이터는 Supabase에서 조회 가능한 상태이며, 이 work unit은 이미 채워진 데이터를 사용합니다.
- 가정: 전체 캠핑장 수가 10~20곳 규모를 유지하는 한, 목록에 페이지네이션이나 무한 스크롤 없이 전부 보여줘도 무리가 없습니다. 데이터 규모가 크게 늘어나면 이 가정은 다시 확인이 필요합니다.

## 범위 밖

- 캠핑장 저장·찜 기능은 포함하지 않습니다. 로그인이 없는 사이트에서 저장을 어떻게 구현할지(브라우저 로컬 저장 등)는 별도 work unit에서 다룹니다.
- 사이트 자체의 사용자 리뷰·평점 작성 기능은 포함하지 않습니다. `PRODUCT.md`가 정한 경계입니다.
- 차박 가능 여부를 포함해, `pet-camping-dataset`이 다루지 않은 조건은 이번 필터에도 포함하지 않습니다.
- 지도나 위치 기반 정렬·검색은 포함하지 않습니다. 이번 논의에서 다뤄지지 않았습니다.

## 유보된 사항

- 목록·상세 화면에 캠핑장 사진을 추가할지, 추가한다면 어떤 방식으로 확보할지는 정하지 않았습니다.
- 반려견 크기 조건이 없는 캠핑장(모든 크기 허용 등 데이터가 비어 있는 경우)을 어떻게 표시할지는 실제 데이터 형태를 보고 정합니다.

## 남은 위험

- 실제 데이터의 요약·캡션 텍스트 길이가 프로토타입에서 가정한 길이와 크게 다르면, 카드와 상세 화면의 레이아웃이 흔들릴 수 있습니다.
- `source_platform`이 `web`인 캠핑장의 실제 비율이 높으면, 추천 영역에 노출될 만한(원본 콘텐츠가 확인된) 캠핑장이 매우 적어질 수 있습니다.

## 검토에 사용한 프로토타입

`prototype.html`에서 화면 구조와 상호작용을 검토했습니다. 다음 화면과 상태를 다룹니다.

- 캠핑장 찾기: 기본 상태, 조건에 맞는 곳 없음 상태
- 캠핑장 상세: 기본 상태(원본 콘텐츠 있음), 공식 정보로 대체된 곳 상태

더미 데이터로 검증했으며, 실제 데이터 연동과 세부 스타일은 구현 단계에서 확정합니다.
